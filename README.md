# Сайт репетитора

Веб-приложение для частного репетитора: расписание занятий, ученики и родители,
домашние задания и оценки, учёт оплат, уведомления на сайте и во ВКонтакте, база
теоретических материалов. Три роли пользователей с разными правами: **репетитор**,
**родитель**, **ученик**.

**Тип проекта:** веб-приложение — одностраничный клиент (SPA на React) и REST API
(FastAPI + PostgreSQL); весь стенд разворачивается одной командой `docker compose up`.

## Что будет уметь приложение

- **Расписание.** Серия занятий задаётся правилом «каждые N недель в такое-то время»;
  из серий автоматически порождаются занятия на 12 недель вперёд. Правка серийного
  занятия — как в Google Calendar: «только это», «это и последующие», «все занятия».
- **Ученики и родители.** Карточки, привязка детей к родителю, учётные записи,
  которые создаёт репетитор, статистика выполнения домашних заданий.
- **Занятие.** Тема, домашнее задание с файлами, оценки и статус выполнения домашки
  по каждому участнику, заметки репетитора и комментарий для родителя.
- **Финансы.** Ставка за занятие, платежи родителей, вычисляемый баланс и долг,
  сводка по родителям и заработок по месяцам.
- **Уведомления.** Колокольчик на сайте и доставка ботом ВКонтакте: напоминания о занятиях,
  публикация домашки, отмены и переносы, напоминания об оплате.
- **Теория.** Дерево тем и материалы в Markdown с файлами, черновики и публикация,
  поиск по названиям.
- **Кабинеты.** Родитель видит детей, их занятия и свой баланс; ученик — только своё
  расписание, домашки и оценки.

## Стек и инструменты

| Слой | Технологии |
|---|---|
| Backend | Python 3.12, FastAPI, SQLAlchemy 2 (async, asyncpg), Alembic, pydantic v2, argon2 |
| База данных | PostgreSQL 16 |
| Frontend | React 18, TypeScript 5, Vite 5, Mantine 7, TanStack Query 5, FullCalendar 6, React Router 6 |
| Фоновые задачи | Отдельный контейнер `worker`: порождение занятий, рассылка уведомлений, бот ВКонтакте |
| Инфраструктура | Docker, docker compose, nginx (раздача статики и прокси `/api`) |
| Процесс | GitHub: Issues, Milestones, ветки по задачам, Pull request с code review |

## Процесс работы

Работа ведётся по четырём спринтам. Каждая задача — Issue с Milestone своего спринта
и исполнителем; под неё заводится отдельная ветка и Pull request. Ветка `main`
меняется только через Pull request после review с одобрением преподавателя.
Правила ветвления, ревью и состав задач по спринтам описаны в
[плане спринтов](./docs/План%20спринтов.md).
