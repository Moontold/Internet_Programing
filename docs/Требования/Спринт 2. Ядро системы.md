## 1. Матрица прав «роль × действие»

Обозначения: **да** — разрешено; **свои** — только данные своих детей (родитель) или свои
(ученик); **нет** — запрещено.

Что получает пользователь при отказе:

| Ситуация | Ответ API | Что видит пользователь |
|---|---|---|
| Не выполнен вход или сессия истекла | `401`, «Требуется вход» / «Сессия истекла, войдите заново» | Переход на страницу входа |
| Раздел чужой роли (например, родитель открывает `/api/students`) | `403`, «Раздел доступен только репетитору» | Интерфейс не показывает пункт меню; ручной переход по адресу ведёт на свою главную |
| Чужое занятие (не участвует ни свой ребёнок, ни сам ученик) | `200`, `error: true`, «Нет доступа к этому занятию» | Сообщение об ошибке на странице занятия |
| Чужой ребёнок в кабинете родителя | `200`, `error: true`, «Нет доступа к этому ученику» | Сообщение об ошибке |
| Чужой файл домашки | `403`, «Нет доступа к файлу» | Файл не скачивается |
| Несуществующая запись | `200`, `error: true`, «…не найдено» / «…не найден» (`404` для файлов) | Сообщение «не найдено» |

### 1.1 Вход и профиль

| Действие | Репетитор | Родитель | Ученик |
|---|---|---|---|
| Войти по логину и паролю | да | да, если учётка активна | да, если учётка активна |
| Выйти | да | да | да |
| Посмотреть свой профиль | да | да | да |
| Сменить свой пароль (нужен текущий) | да | да | да |
| Восстановить пароль самостоятельно | нет: пароль задаётся в `.env` | нет: сбрасывает репетитор | нет: сбрасывает репетитор |

### 1.2 Родители и ученики

| Действие | Репетитор | Родитель | Ученик |
|---|---|---|---|
| Список родителей / учеников, фильтр «Только активные» | да | нет | нет |
| Карточка родителя (контакты, дети) | да | нет | нет |
| Карточка ученика (класс, формат, ставка, расписание, статистика) | да | нет | нет |
| Создать родителя / ученика, задать логин и пароль | да | нет | нет |
| Изменить карточку, перепривязать ученика к другому родителю | да | нет | нет |
| Деактивировать / активировать | да | нет | нет |
| Сбросить пароль (новый пароль показывается один раз) | да | нет | нет |
| Список своих детей со статистикой домашек и регулярным расписанием | — | свои | — |

### 1.3 Расписание

| Действие | Репетитор | Родитель | Ученик |
|---|---|---|---|
| Календарь всех занятий (неделя, месяц, список недели на телефоне) | да | нет | нет |
| Создать серию или разовое занятие | да | нет | нет |
| Перенести, изменить длительность и состав занятия (с выбором области) | да | нет | нет |
| Отменить занятие | да | нет | нет |
| Удалить занятие | да, кроме проведённого | нет | нет |
| Изменить правило серии, остановить серию | да | нет | нет |
| Занятия за период | все | свои | свои |
| Регулярное расписание (действующие серии) | любого ученика | своих детей | своё |

### 1.4 Карточка занятия

| Поле или действие | Репетитор | Родитель | Ученик |
|---|---|---|---|
| Открыть карточку | любое занятие | свои | свои |
| Тема, время, формат, статус | видит и правит | видит | видит |
| Текст домашки и файлы | видит, правит, прикрепляет и удаляет | видит, скачивает | видит, скачивает |
| Статус домашки и оценка участника | видит и выставляет | свои | свои |
| Ставка участника за занятие | видит и правит | свои | нет |
| Комментарий для родителя | видит и правит | видит | нет |
| Заметки репетитора | видит и правит | нет | нет |
| Другие участники группового занятия | всё | только имена | только имена |
| Оценка за предыдущую домашку | да, если в занятии один ученик | да, если в занятии один его ребёнок | да |

Отменённое занятие не редактирует никто: ни расписание, ни тему, ни домашку, ни оценки,
ни файлы. Просмотр отменённого занятия остаётся доступен.

## 2. Пользовательские сценарии

Формат: кто выполняет, с чего начинается, основной ход и ответвления с ожидаемым текстом.

### С-1. Вход в систему

- **Кто:** любой пользователь.
- **Предусловие:** учётная запись создана (репетитор — при первом старте из `.env`, остальные — репетитором).

1. Пользователь открывает сайт и попадает на страницу входа.
2. Вводит логин и пароль, нажимает «Войти».
3. Система открывает главную страницу его роли: репетитор — «Расписание», родитель —
   «Дети», ученик — «Расписание» своего кабинета.
4. Сессия сохраняется 30 дней и продлевается при работе; повторный вход не нужен,
   в том числе после перезапуска сервера.

Ответвления:

- Неверный логин или пароль → «Неверный логин или пароль». Сообщение одинаковое для
  несуществующего логина и неверного пароля.
- Учётка деактивирована → «Учётная запись отключена. Обратитесь к репетитору.»
- 10 неудачных попыток за 15 минут → «Слишком много неудачных попыток входа. Попробуйте
  через 15 минут.» Блокируется вход только по этому логину; другие пользователи входят.
- Забыт пароль → на странице входа подсказка «Попросите преподавателя сбросить его».

### С-2. Заведение родителя и ученика

- **Кто:** репетитор.

1. «Родители» → «Добавить»: ФИО, телефон, контакты, логин и пароль (от 8 символов).
2. Система показывает окно с паролем один раз, с кнопкой «Скопировать». Репетитор
   передаёт логин и пароль родителю.
3. В карточке родителя — «Добавить ребёнка»: ФИО, класс (1–11, необязательно), формат
   (онлайн / офлайн), ставка за занятие, логин и пароль. Окно с паролем — так же один раз.
4. Ребёнок появляется в карточке родителя и в списке «Ученики» с именем родителя.

Ответвления:

- Логин занят → «Такой логин уже занят».
- Логин короче 3 символов или содержит кириллицу и пробелы, пароль короче 8 символов →
  форма подсвечивает поле, запись не создаётся.
- Ученик без родителя не создаётся: родитель выбирается обязательно.
- Сброс пароля → новый пароль из 10 символов показывается один раз; все сессии
  пользователя завершаются.
- Деактивация → пользователь не может войти, его сессии завершаются; в новые занятия
  и серии его добавить нельзя («Ученик деактивирован: …»). История занятий сохраняется.

### С-3. Создание серии занятий

- **Кто:** репетитор.

1. В календаре — клик по пустому времени или кнопка «Добавить занятие».
2. Форма: дата и время, длительность (15–480 минут), ученики (один или несколько),
   название, флажок «Повторять каждую неделю», «Раз в N недель» (1–8), «До какой даты
   (необязательно)».
3. С флажком создаётся серия, без флажка — разовое занятие.
4. Занятия серии появляются в календаре сразу на 12 недель вперёд. Worker дополняет
   горизонт раз в час, так что через неделю в календаре снова видно 12 недель.
5. Если первое занятие указано в прошлом, прошедшие занятия сразу получают статус «проведено».

Ответвления:

- Дата окончания раньше первого занятия → «Дата окончания серии раньше первого занятия».
- Среди учеников есть деактивированный → «Ученик деактивирован: <ФИО>».
- Серия без даты окончания бессрочна.

### С-4. Перенос занятия

- **Кто:** репетитор.

1. Перетаскивание занятия в календаре, пункт «Перенести…» в контекстном меню или кнопка
   «Перенести» в карточке занятия.
2. Для серийного занятия система спрашивает область: «Только это занятие», «Это и
   последующие занятия», «Все занятия серии» (правила — раздел 3).
   Для разового занятия вопрос не задаётся.
3. Календарь показывает новое расписание; сообщение «Занятие перенесено».

Ответвления:

- Проведённое занятие → «Проведённое занятие нельзя перенести». Пункта «Перенести…» в меню
  нет. Перенос проведённого для исправления записи появится в спринте 3 (Issue #31).
- Отменённое занятие → «Отменённое занятие нельзя редактировать».
- «Все занятия серии» со сдвигом ровно на целое число периодов (например, на неделю
  в еженедельной серии) → «Сдвиг на целое число периодов серии накладывает занятия друг
  на друга. Перенесите занятия по одному или остановите серию и создайте новую.»

### С-5. Отмена и удаление занятия

- **Кто:** репетитор.

1. Контекстное меню занятия → «Отменить» (или «Удалить»).
2. Для серийного занятия система спрашивает область: «Только это занятие» или
   «Это и последующие занятия».
3. Отменённое занятие остаётся в истории со статусом «отменено» и не списывается со
   счёта (спринт 3); удалённое пропадает из всех списков.

Ответвления:

- Повторная отмена → «Занятие уже отменено».
- Удаление проведённого → «Проведённое занятие нельзя удалить, только отменить».
- Отменить можно и проведённое занятие: например, если ученик не пришёл и занятие не оплачивается.

### С-6. Домашнее задание и оценка

- **Кто:** репетитор; результат видят ученик и родитель.

1. Репетитор открывает карточку занятия, заполняет «Тему занятия» и «Текст домашнего
   задания», нажимает «Сохранить домашку», прикрепляет файлы («Прикрепить файл», до 50 МБ).
2. После занятия в таблице «Участники» выставляет каждому ученику статус домашки
   («не проверено» / «сделано» / «не сделано») и оценку от 2 до 5.
3. Ученик в разделе «Занятия» видит тему, домашку, файлы и свою оценку; у проведённых
   занятий с несделанной домашкой — плашка «Домашка не выполнена».
4. Родитель в разделе «Дети» видит то же по каждому ребёнку и статистику: долю сделанных
   домашек среди проверенных и среднюю оценку.

Ответвления:

- Файл больше лимита → «Файл больше 50 МБ».
- Ученик не участвует в занятии → «Ученик не участвует в этом занятии».
- Оценку можно снять: поле очищается, в статистике она не учитывается.

## 3. Правила правки серии

### 3.1 Понятия

- **Серия** — правило «каждые N недель, начиная с даты первого занятия, в то же время
  и с той же длительностью», состав учеников и необязательная дата окончания.
- **Место занятия в серии** (`original_start`) — время, которое занятию даёт правило.
  Фактическое время (`scheduled_start`) может отличаться, если занятие переносили отдельно.
- **Отделённое занятие** (`detached`) — занятие серии, изменённое отдельно от неё:
  перенос, длительность или состав с областью «только это», а также отмена «только это».
  Отделённое занятие остаётся в серии, но правка правила его не двигает.
- **Удалённое занятие** не показывается нигде, но продолжает занимать своё место в серии:
  worker не порождает на этом месте новое занятие.

### 3.2 Что и где меняется

| Действие | «Только это» | «Это и последующие» | «Все занятия» |
|---|---|---|---|
| Перенос, длительность, состав | Меняется одно занятие, оно становится отделённым | Серия заканчивается накануне этого занятия; с него начинается новая серия с новыми параметрами | Правило серии сдвигается на ту же дельту; меняются все запланированные неотделённые занятия |
| Отмена | Занятие отменено (и отделено) | Серия заканчивается накануне; это занятие отменено; последующие запланированные снимаются | недоступно |
| Удаление | Занятие скрыто | Серия заканчивается накануне; это и последующие запланированные скрыты | недоступно |

**Тема, комментарий для родителя, заметки и домашка** всегда относятся к одному занятию:
диалог выбора области для них не показывается.

**Разовое занятие** (вне серии) правится только в режиме «только это»: диалог выбора
области не показывается.

### 3.3 Правила, общие для всех областей

1. Проведённые занятия при правке серии не меняются никогда: ни время, ни длительность,
   ни состав, ни ставки и оценки.
2. Проведённое занятие нельзя перенести и удалить, только отменить.
3. Отменённое занятие не редактируется.
4. Отделённые занятия сохраняют своё фактическое время, длительность и состав при правке
   «все занятия». При правке «это и последующие» они переходят в новую серию
   с сохранением своего времени.
5. Отменённые и удалённые занятия держат своё место: после правки серии на их месте
   новое занятие не появляется.
6. Новые занятия при правке порождаются только в будущем, на горизонт 12 недель.
7. Сдвиг «всех» ровно на целое число периодов серии запрещён: занятия наложились бы на
   соседние места. Нужно перенести занятия по одному или остановить серию и создать новую.
8. Изменение даты окончания серии: запланированные занятия после новой даты снимаются
   (обычные удаляются, отделённые отменяются); продление даты порождает недостающие занятия.

### 3.4 Пример

Серия «Алгебра» у Маши: каждый вторник 17:00–18:00, с 06.10.2026, бессрочно.
Сегодня — среда 14.10.2026: занятия 06.10 и 13.10 проведены, дальше запланированы
20.10, 27.10, 03.11, 10.11 и так далее на 12 недель.

| Действие репетитора | Результат |
|---|---|
| Перенести 27.10 на четверг 29.10 18:00, «только это» | Занятие 29.10 18:00 отделено от серии; остальные вторники в 17:00 |
| Затем перенести 20.10 на 18:00, «все занятия» | Все запланированные вторники сдвигаются на 18:00: 20.10, 03.11, 10.11…; 29.10 остаётся на четверге 18:00; 06.10 и 13.10 остаются в 17:00 |
| Затем перенести 03.11 на среду 04.11 16:00, «это и последующие» | Старая серия заканчивается 02.11 (20.10 и 29.10 остаются в ней). Новая серия — каждая среда 16:00 с 04.11. Занятие 03.11 переезжает на 04.11 со своей темой и домашкой |
| Отменить 11.11, «только это» | 11.11 — отменено; новое занятие на 11.11 не порождается |
| Удалить 18.11, «это и последующие» | Новая серия заканчивается 17.11; 18.11 и следующие запланированные пропадают из календаря |
| Перенести 13.10 (проведено) | Отказ: «Проведённое занятие нельзя перенести» |
| Перенести 20.10 на неделю вперёд, «все занятия» | Отказ: сдвиг на целое число периодов |

## 4. Тест-кейсы приёмки ядра

Прогоняются на стенде `docker compose` после влития задач спринта, в браузере
(для проверок прав — также через Swagger UI `http://localhost/api/docs`).

**Подготовка данных:** репетитор `tutor` (из `.env`); родитель «Иванова Анна» (`ivanova`)
с детьми «Иванова Маша» (`masha`, 8 класс, онлайн, 1500 ₽) и «Иванов Петя» (`petya`,
5 класс, офлайн, 1200 ₽); родитель «Смирнов Олег» (`smirnov`) с сыном «Смирнов Дима» (`dima`).
Подготовку данных выполняют ТК-03 и ТК-04.

| № | Проверка | Шаги | Ожидаемый результат |
|---|---|---|---|
| ТК-01 | Вход репетитора | Открыть `http://localhost/`, войти `tutor` с паролем из `.env` | Открыта страница «Расписание»; в меню «Расписание», «Ученики», «Родители», «Профиль» |
| ТК-02 | Неверный пароль и блокировка | 1) Войти `tutor` с неверным паролем. 2) Повторить ещё 9 раз. 3) Войти с верным паролем | 1) «Неверный логин или пароль». 3) «Слишком много неудачных попыток входа. Попробуйте через 15 минут.»; через 15 минут вход проходит |
| ТК-03 | Создание родителя | «Родители» → «Добавить» → Иванова Анна, логин `ivanova`, пароль `parent123` | Окно с паролем `parent123` и кнопкой «Скопировать»; родитель в списке |
| ТК-04 | Создание детей | В карточке Ивановой «Добавить ребёнка» — Маша и Петя; затем Смирнов и Дима | Дети в карточке родителя и в списке «Ученики» с родителем |
